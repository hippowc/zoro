# Git 常用操作

## 丢弃本地修改
@index git checkout reset 丢弃 还原
@shell git checkout reset 丢弃 还原
```bash
git checkout -- <file>
git reset --hard HEAD
```

退掉没提交的改动前，先确认真的不要了。

## 查看历史
@index git log 历史 提交 查看
@shell git log 历史 提交 查看
```bash
git log --oneline --graph -10
```

## 暂存改动
@index git stash 暂存 恢复
@shell git stash 暂存 恢复
```bash
git stash
git stash pop
```
